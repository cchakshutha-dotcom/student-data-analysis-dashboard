# Student Data Analysis Dashboard 📊🎓

A Python-based Student Data Analysis project for exploring, analyzing, and visualizing student datasets using Excel data and various data visualization techniques.

---

# 📁 Project Structure

Student-Data-Analysis-Dashboard/
│
├── all.py                  ← Combined analysis script
├── bar.py                  ← Bar chart visualization
├── eda.py                  ← Exploratory Data Analysis script
├── hist.py                 ← Histogram visualization
├── line.py                 ← Line chart visualization
├── newall.py               ← Updated combined analysis script
├── pie.py                  ← Pie chart visualization
├── piechart.png            ← Generated pie chart image
├── student.xlsx            ← Student dataset
└── README.md               ← Project documentation

---

# 🚀 How to Run the Project

## Step 1 — Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

---

## Step 2 — Open Project Folder

Open the extracted project folder in:

- VS Code
- PyCharm
- Jupyter Notebook
- Command Prompt

---

## Step 3 — Run EDA Script

```bash
python eda.py
```

This script performs:
- Dataset loading
- Data exploration
- Statistical analysis

---

## Step 4 — Run Visualization Scripts

### Run Bar Chart

```bash
python bar.py
```

### Run Histogram

```bash
python hist.py
```

### Run Line Graph

```bash
python line.py
```

### Run Pie Chart

```bash
python pie.py
```
